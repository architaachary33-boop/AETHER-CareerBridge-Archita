# CareerBridge

An internship and job application portal for students.

## Problem
Students find opportunities on many websites and messages, and track deadlines in notes or spreadsheets. Deadlines get missed and application status is unclear. CareerBridge gives students one place to find, apply and track, and gives admins one panel to manage opportunities.

## User Roles
- **Student:** register, create profile with skills, browse and filter opportunities, apply, track application status
- **Admin:** log in, add, edit and manage opportunities, review applicants, view statistics

## Must Have Features
- Student registration and login
- Profile with skills
- Opportunity listings
- Search and filters by skill and domain
- Apply to an opportunity
- Application status tracking
- Admin panel for managing opportunities
- Dashboard with application statistics

## Stretch Features
- Resume upload
- Skill-match percentage
- Application timeline
- Deadline reminders

## Tech Stack
- Frontend: React
- Backend: Node.js + Express
- Database: PostgreSQL
- Tools: Git, GitHub, VS Code, Postman
