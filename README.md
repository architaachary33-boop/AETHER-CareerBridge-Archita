# CareerBridge

An internship and job application portal for students.

## Problem
Students find opportunities on many websites, groups and messages, and track deadlines in notes or spreadsheets. Deadlines get missed and the application status is unclear. CareerBridge gives students one place to find opportunities, apply and track their applications, and gives admins one panel to manage opportunities.

## User Roles
- **Student:** register and log in, browse and filter opportunities, view details, apply, track application status
- **Admin:** log in, create, edit and delete opportunities, review applicants, update application status

## Core Workflow
Admin publishes an opportunity → Student finds it → Student applies → Student tracks the application.

## Planned Features
**Must have**
- Register and login for Student and Admin
- Opportunity listing with search and filters
- Opportunity details and Apply
- My Applications with status tracking
- Admin panel to manage opportunities and update statuses

**Stretch**
- Resume upload
- Skill-match percentage
- Application timeline
- Deadline reminders

## Tech Stack
- Frontend: React
- Backend: Node.js + Express
- Database: PostgreSQL
- Tools: Git, GitHub, VS Code, Postman
